# Circa apps

The watch apps of [Circa](https://github.com/Msoenn/circa-manifest), an unofficial LineageOS 23.2 fork for the
round Pixel Watch 2 without Google services. Circa's OS changes (quick-settings shade, keyguard, button policy,
overlays) live in its forks of `frameworks/base` and `device/circa`; the apps here are the rest of the watch:

| App | Package | What it is |
|---|---|---|
| [launcher](launcher/README.md) | `org.circa.launcher` | Watch faces, app list, tiles, always-on display, tilt-to-wake |
| [watchlink](watchlink/README.md) | `org.circa.watchlink` | Phone link: looks like a Bangle.js to Gadgetbridge; notifications, heart rate, steps, weather, media, agenda ([data contract](watchlink/DATA-CONTRACT.md)) |
| [settings](settings/README.md) | `org.circa.settings` | Round Settings (stock Wear's order); AOSP Settings stays as the backend |
| [clock](clock/README.md) | `org.circa.clock` | Alarms, timers, stopwatch; replaces DeskClock |
| [companion](companion/README.md) | `org.circa.companion` | Media, Weather, Agenda, Find phone, Flashlight |
| [keyboard](keyboard/README.md) | `org.circa.keyboard` | Round full-screen keyboard (the only IME) |
| [exercise](exercise/README.md) | `org.circa.exercise` | Workouts with heart-rate zones, GPS, sync to Gadgetbridge |

`shared/symbols` is the one copy of the Material Symbols (Rounded) icons all Compose apps use, generated by
`tools/gen-symbols.py` from `tools/symbols/names.txt`.

## Build

```bash
./build-all.sh                     # all apps: JVM tests + release builds + signing -> prebuilt/
./build-all.sh --only launcher,watchlink
```

Needs `curl`, `unzip` and network access for the first run: a JDK 17 and the Android SDK are fetched into
`.toolchain/` unless `JAVA_HOME` / `ANDROID_HOME` point at existing ones, and Gradle fetches its dependencies.
Signing keys come from `CIRCA_KEYS`, else `$ANDROID_BUILD_TOP/build/make/target/product/security`, else they are
fetched from AOSP. Output: `prebuilt/<Module>.apk`, plus a generated `prebuilt/Android.bp` (`android_app_import`
modules) and `prebuilt/packages.mk`.

In a Circa source tree this repository is checked out at `vendor/circa-apps` by the manifest. Run
`vendor/circa-apps/build-all.sh` before building the image: `device/circa` inherits `circa-apps.mk`, which adds
the modules once `prebuilt/` exists (without it the image builds without the apps). The configuration the apps
need from the platform (privileged and default permissions, the launcher's framework overlay) is in
`device/circa/apps`.

Each app is also an ordinary Gradle project (`cd launcher && ./gradlew :app:testDebugUnitTest`).
