# Circa Material Symbols (Rounded) - the one icon set every Circa UI uses.
#
# Input to tools/gen-symbols.py. One entry per line:
#
#   <name> [target ...]
#
# <name> is a Material Symbols name from google/material-design-icons
# (symbols/web/<name>/materialsymbolsrounded/). Both the filled
# (<name>_fill1_24px.svg) and the outlined (<name>_24px.svg) variant are fetched
# and emitted as `CircaSymbols.Filled.<PascalName>` / `CircaSymbols.Outlined.<PascalName>`.
#
# Optional targets also emit a platform vector drawable (for code that cannot use
# the Compose ImageVector):
#
#   sysui     -> <SystemUI>/res/drawable/circa_ic_<name>.xml            (filled)
#   keyboard  -> apps/keyboard/.../res/drawable/circa_ic_<name>.xml     (filled)
#                                            circa_ic_<name>_outlined.xml (outlined)
#
# Blank lines and # comments are ignored. Run:  tools/gen-symbols.py
